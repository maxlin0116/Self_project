# MeArm v1 Hardware Files

This folder contains the MeArm v1 mechanical files copied from:

https://github.com/maxlin0116/MeArm/tree/master/v1

## Files

- `v1/MeArmV1.0.dxf` - MeArm v1.0 laser cutting file.
- `v1/MeArmV1.0_r1.4.pdf` - MeArm v1.0 assembly/print guide.
- `v1/MeArmV1.1.dxf` - MeArm v1.1 laser cutting file.
- `v1/MeArmV1.1.pdf` - MeArm v1.1 assembly/print guide.

## How To Open

- Open PDF files in a browser, Adobe Reader, or the VS Code PDF extension.
- Open DXF files with LibreCAD, Inkscape, AutoCAD, Fusion 360, LightBurn, or the laser cutter software.

## Notes

The DXF files are for 3 mm laser-cut sheet material. The arm still needs servos,
screws, wiring, and controller code.
